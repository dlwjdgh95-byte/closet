# 옷 데이터 구조

옷을 **슬롯(어디에 입는가) × 속성(어떤 옷인가)** 으로 분류하고, 브랜드의 관점은 별도 브랜드 프로필로 관리합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `data/wardrobe.yaml` | 옷 목록 (한 벌에 한 항목) |
| `data/brands.yaml` | 브랜드 프로필 (무드, 기본 격식, 실루엣 성향, 관점) |
| `data/moods.yaml` | 무드 태그 사전과 무드 간 궁합 |
| `data/colors.yaml` | 색 사전 (무채색 여부 포함) |
| `data/tpo.yaml` | TPO별 허용 격식 범위 |
| `scripts/validate.py` | 위 파일들의 형식 검증 |

## 슬롯

한 코디는 슬롯마다 최대 한 벌입니다.

| 슬롯 | 예시 | 코디에서 |
|---|---|---|
| `outer` 아우터 | 코트, 패딩, 재킷, 가디건 | 날씨에 따라 |
| `top` 상의 | 셔츠, 니트, 티셔츠, 맨투맨 | 필수 |
| `bottom` 하의 | 슬랙스, 데님, 치노 | 필수 |
| `shoes` 신발 | 구두, 로퍼, 스니커즈, 부츠 | 필수 |
| `accessory` 액세서리 | 가방, 머플러, 모자, 시계 | 선택 |

상의 레이어링(이너·미들 분리)은 아직 다루지 않습니다. 필요해지면 `top`에 `layer` 필드를 추가하는 방식으로 확장합니다.

## 옷 속성 (`wardrobe.yaml`)

| 필드 | 값 | 쓰임 |
|---|---|---|
| `id` | `top-001`처럼 고유 | 착용 기록·피드백 연결 |
| `name` | 자유 | 표시 |
| `slot` | 위 슬롯 중 하나 | 조합 뼈대 |
| `category` | 자유 (`coat`, `shirt` 등) | 표시, 이후 세부 규칙 |
| `brand` | `brands.yaml`의 키, 없으면 생략 | 무드·관점 상속 |
| `color.primary` | `colors.yaml`의 키 | 색 조합 |
| `color.secondary` | 선택, 패턴의 두 번째 색 | 색 조합 |
| `color.tone` | `light` / `medium` / `dark` | 명암 대비 |
| `formality` | 1~5 (아래 척도) | TPO 필터, 격식 일관성 |
| `fit` | `slim` / `regular` / `relaxed` / `oversized` | 실루엣 균형 |
| `warmth` | 1~5 (아래 척도) | 날씨·계절 |
| `pattern` | `solid` / `stripe` / `check` / `dot` / `graphic` / `other` | 패턴 충돌 방지 |
| `material` | `cotton`, `wool`, `denim` 등 | 계절감, 격식 보정 |
| `mood_override` | 선택, 무드 태그 1~3개 | 브랜드 전형과 다른 옷의 무드 |
| `photo` | 선택, 사진 경로 | 사진 입력 연동 |
| `notes` | 선택 | 메모 |

계절 태그는 따로 두지 않고 `warmth`로 대신합니다. 기온과 바로 대응되어 날씨 반영이 쉽습니다.

### 격식 척도

| 값 | 의미 | 예시 |
|---|---|---|
| 1 | 홈웨어·추리닝 | 트레이닝복, 슬리퍼 |
| 2 | 편한 캐주얼 | 맨투맨, 데님, 스니커즈 |
| 3 | 단정한 캐주얼 | 니트, 치노, 로퍼 |
| 4 | 비즈니스 캐주얼 | 옥스퍼드 셔츠, 슬랙스, 울 코트 |
| 5 | 정장 | 수트, 넥타이, 드레스 슈즈 |

### 보온도 척도 (추천 로직에서 조정 예정)

| 값 | 대략의 기온 | 예시 |
|---|---|---|
| 1 | 25℃ 이상 | 반팔, 린넨 |
| 2 | 18~25℃ | 얇은 셔츠, 면바지 |
| 3 | 10~18℃ | 맨투맨, 가벼운 재킷 |
| 4 | 3~10℃ | 니트, 트렌치 |
| 5 | 3℃ 미만 | 패딩, 울 코트, 머플러 |

## TPO (`tpo.yaml`)

TPO는 옷에 태그하지 않고 허용 격식 범위로 표현합니다. 코디의 모든 옷이 범위 안에 들어야 후보가 됩니다.

| TPO | 격식 범위 | 근거 |
|---|---|---|
| 출퇴근 | 2~4 | 복장 자유, 추리닝만 제외 |
| 친목모임 | 2~3 | 편하고 단정하게 |
| 데이트 | 3~4 | 한 단계 갖춰서 |

## 브랜드 프로필 (`brands.yaml`)

옷에는 브랜드 키만 적고, 브랜드가 추구하는 관점은 프로필에 한 번만 정의합니다. 그 브랜드의 옷은 모두 프로필을 물려받습니다.

| 필드 | 내용 |
|---|---|
| `moods` | 무드 태그 1~3개 |
| `formality` | 기본 격식 범위 (사진 입력 시 격식 초안의 기준) |
| `silhouette` | 실루엣 성향 `slim` / `regular` / `relaxed` |
| `note` | 브랜드 관점 한 줄 |

**무드 결정 순서:** 옷의 `mood_override` → 브랜드 `moods`. 브랜드가 없는 옷은 `mood_override`가 필수입니다.

## 무드 (`moods.yaml`)

무드 일관성은 색·격식·핏에 이은 네 번째 밸런스 축입니다. 같은 무드끼리와 `good` 쌍은 가점, `clash` 쌍은 감점, 나머지는 중립입니다. 태그 목록은 실제로 입는 브랜드가 정해지면 다듬습니다.

## 밸런스 축 요약 (3단계 추천 로직의 입력)

| 축 | 사용 필드 |
|---|---|
| 색 조합 | `color.primary`, `color.secondary`, `color.tone`, `colors.neutral`, `pattern` |
| 격식 | `formality` (TPO 범위 + 옷 간 편차) |
| 핏 | `fit` (위아래 실루엣 균형) |
| 무드 | `mood_override` 또는 브랜드 `moods` |
| 날씨 | `warmth`, `material` |

## 사진 입력 흐름

1. 옷 사진을 올리면 Claude가 슬롯, 색, 톤, 패턴, 핏, 격식, 보온도 초안을 채웁니다. 라벨이나 로고가 보이면 브랜드도 채웁니다.
2. 소재·두께와 평소 입는 핏은 사진만으로 부정확하므로 한마디 덧붙여 주시면 좋습니다.
3. 검수가 끝나면 `wardrobe.yaml`에 추가하고 `python3 scripts/validate.py`로 확인합니다.
